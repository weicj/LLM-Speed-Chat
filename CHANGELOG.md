# Changelog

## 0.1.0

Initial public-ready beta focused on one job: benchmarking local OpenAI-compatible LLM chat performance during real multi-turn interaction.

Included in this release:

- text-first multi-turn chat UI
- automatic model discovery from `/v1/models`
- live prefill/decode/token/wall-time metrics
- request cancellation and draft recovery
- wheel, source distribution, and container smoke coverage
